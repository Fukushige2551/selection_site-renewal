セレクション 店舗情報更新ツール 1.0.0

対象
http://foods-selection.co.jp.testrs.jp/ の既存店舗10件。
WordPressの管理者権限と、Secure Custom Fields / ACFが必要です。
本番ドメインでは実行できません。

手順
1. STGのデータベースとアップロード画像をバックアップする。
2. 管理画面「プラグイン → 新規プラグインを追加 → プラグインのアップロード」で foods-shop-updater.zip をアップロードし、有効化する。
3. 「ツール → 店舗情報更新」で10店舗の照合結果と変更差分を確認する。
4. 内容が正しければ確認欄にチェックし、「バックアップを保存して差分を反映」を押す。
5. 「前回の更新前バックアップをダウンロード」からJSONを保存する。
6. 各店舗ページでアクセス、決済24種類、サービス、URLを確認する。

照合と更新範囲
店舗名の完全一致で照合するため、Local WPとSTGの投稿IDが違っても照合できます。
店舗名が重複・未登録・非公開、スラッグが競合、フィールド定義や選択肢が不一致の場合、更新を止めます。
スラッグ、access、payment_methods、available_services、atm_bank_nameだけを差分更新します。
画像、本文、営業時間、住所、電話番号、他のページは更新対象に含みません。
選択肢の順番や改行コードだけの違いは更新しません。
店舗スラッグ変更時はWordPress標準の旧スラッグ転送情報が作成されます。旧URLの転送も実環境で確認してください。
確認から15分経過した場合や確認後にデータが変わった場合は、ページを再読み込みして再確認します。

バックアップ
更新前の対象項目と旧スラッグ情報をWordPressのoptionsテーブルへ保存します。
公開URLへバックアップファイルを作成せず、管理者権限とnonce確認を通じてダウンロードします。
失敗時は対象項目の更新前状態へ復元を試みます。復元失敗の表示が出た場合は再実行せず、JSONバックアップを保存して管理者に確認してください。
これは対象項目だけのバックアップです。サイト全体の復元用バックアップを置き換えるものではありません。
プラグイン削除時にもバックアップはDBに残します。

テーマの表示対応
同時に提供する foods-shop-theme-display.zip は、Local WPで更新済みの functions.php と single-shop.php の全ファイルです。
現在のSTGテーマの同名ファイルをバックアップし、STG独自変更がないか比較してから、対象テーマの同名ファイルへ反映してください。
テーマフォルダ：wp-content/themes/foods-selectioncojp-theme/
このZIPはプラグインとしてインストールしません。2ファイルをテーマ側へ反映するためのものです。
テーマ対応により、ATM銀行名の表示・編集と宅急便の「持込不可」削除、車いす設置の表記が反映されます。
テーマ対応前でもツールはデータ更新できますが、古いテーマでは銀行名が表示されず、「持込不可」が残る場合があります。
テーマ反映後、銀行名の管理項目を確認し、プラグインは無効化できます。

資料
各店サービス.docx、決済情報テキスト.docx、店舗アクセス.docx。
確認済み事項：しいの木店＝しいの木台店、決済情報は全10店舗共通、宅急便の「持込不可」は削除。

検証
PHP構文チェック、店舗照合の正常・異常ケース、選択肢比較、変更検出をテスト済み。
Local WPで10店舗の照合・差分0件の確認画面を検証済み。STGでは未実行です。
